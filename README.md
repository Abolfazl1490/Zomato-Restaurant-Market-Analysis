# Zomato-Restaurant-Market-Analysis
Restaurant market analysis using Excel and Tableau
 Zomato Restaurant Market Analysis
Project Overview
This project explores the restaurant landscape in Bangalore using Zomato restaurant listing and rating data. The goal is to understand restaurant distribution, customer ratings, voting patterns, cuisine listings, and online ordering availability through interactive Tableau dashboards.
Business Questions
What is the overall average restaurant rating?
How are restaurant ratings distributed?
Which locations have the highest number of restaurant records?
Which cuisine values appear most frequently?
How many restaurant records indicate online ordering availability?
How do restaurant ratings vary across locations?
What patterns can be observed between restaurant ratings and votes?
Tools Used
Microsoft Excel: Data cleaning and preparation
Tableau: Data visualization and interactive dashboard development
GitHub: Project documentation and portfolio presentation
Data Cleaning
The dataset was prepared in Excel before being used in Tableau. Data preparation included reviewing data quality, checking duplicate records, and cleaning relevant fields such as ratings, votes, cost, and categorical values.
Dashboard Preview
1. Zomato Restaurant Market Overview
This dashboard presents key performance indicators and an overview of restaurant ratings, location distribution, cuisine listings, and online ordering availability.
2. Restaurant Ratings & Performance Insights
This dashboard explores the relationship between restaurant ratings and votes and compares average ratings across locations.
Key Findings
The average restaurant rating in the analyzed dataset is approximately 3.70 out of 5.
The 3.0–3.9 rating band contains the largest number of records among the rating groups shown in the dashboard.
North Indian is the most frequently appearing cuisine value in the analyzed cuisine field.
30,359 restaurant records indicate online ordering availability, compared with 21,248 records without online ordering availability.
BTM has the highest number of restaurant records among the locations analyzed, with 5,109 records.
Limitations
The dataset describes restaurant listings, ratings, votes, and service attributes; it does not represent actual sales or transaction records.
Online ordering availability does not indicate the number of orders completed.
Votes and ratings reflect the dataset's recorded values and should not be interpreted as proof of customer satisfaction for every restaurant.
Findings depend on the dataset's coverage, completeness, and collection period.
How to Open the Project
Download the Tableau packaged workbook (.twbx) from this repository.
Open it using Tableau Desktop or a compatible Tableau application.
Navigate between the dashboards and interact with the available filters.
